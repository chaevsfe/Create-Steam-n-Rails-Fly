# Create Fly: Steam 'n' Rails

Expands Create's train and steam systems with custom tracks, semaphores, conductors, bogeys, buffers, couplers and track palettes.

> [!IMPORTANT]
> **This is an unofficial port.** It is not affiliated with or endorsed by
> The Railways Team. 
> Please report problems here.

## Compatibility

| Component | Version |
| --- | --- |
| Minecraft | `26.2` |
| Mod loader | Fabric Loader `0.19.3` or newer |
| Create Fly | `6.0.9-1` or newer |
| Fabric API | required |
| Java | `25` or newer |
| Environments | Client and server |

## Building

```
git clone https://github.com/chaevsfe/Create-Steam-n-Rails-Fly
cd Create-Steam-n-Rails-Fly
./gradlew build
```

Requires JDK 25.
